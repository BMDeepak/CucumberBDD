Automation test script based on BDD and POM written using Cucumber ,Java Selenium Webdriver , Testng framework.
What you can find in this script :
1. Feature files.
2. Glue code.
3. POM Design structure.
4. Tags.
5. Hooks.
6. Background.
7. Report generation to track test Status.
